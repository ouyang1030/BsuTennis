# Data Analysis Lessons

Each lesson is an executable page built on open data.

- [Win probability and important points](Win_Probability.md): from points to games to
  matches, a match point by point, and the points that mattered
- [Elo ratings](Elo_Ratings.md): rating every tour match since 2000, careers, and how well
  ratings predict compared with the ranking
- [Player profiles](Player_Profiles.md): a season of serve and return statistics, serve
  against return, percentile pizzas and radar charts
- [Serve patterns](Serve_Patterns.md): where first and second serves go, what each target
  earns, predictable servers, and a game-theory test of serve mixing
- [Rally length](Rally_Length.md): how long points last by surface, the fading serve
  advantage, how points end, and who wins the long rallies
- [Shot value](Shot_Value.md): how much every stroke changes its hitter's chance of winning
  the point; returns, lanes, shot types and players
